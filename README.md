# SpotiFLAC-Mobile-drive

Fork with Google Drive upload sample and APK build workflow.

## Included
- `.github/workflows/android-build.yml` to build debug APK
- `drive/DriveUploader.kt` sample uploader
- `drive/UploadWorker.kt` sample background upload worker
- `drive/README_DRIVE.md` setup guide

Este repo es un base de integración. Debes importar el proyecto Android original y adaptar package names.
